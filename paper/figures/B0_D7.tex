\paragraph*{The code-block-matched control we could not build.}
\vekalet{Selecting pairs on pronoun use also selects fewer refusals, fewer code blocks and fewer tokens (\S\ref{sec:dial}), and the control reported there matches the first two but not the third. We tried to build the third. The pool is not what stops it: of the $269{,}665$ usable preference pairs, $158{,}802$ carry no difference in second-person rate at all, so pairs without a pronoun signal are abundant. The matching is what stops it. Required to reproduce the pronoun-selected set's joint distribution over refusal rate, length and code blocks while carrying no pronoun difference, the largest set we could assemble holds $3{,}348$ pairs; across 3 ways of coding the code-block axis the ceiling runs from $1{,}674$ to $3{,}348$, against the $7{,}537$ pairs each training run uses. We did not run the control at a reduced size: the smaller run already reported (\S\ref{sec:dial}) moves no counter, so a null at this data size would not be readable. We report the attempt and its ceiling instead, and the code-block confound stays open.}
