\paragraph*{The code-block-matched control, at the size it allows.}
\vekalet{Selecting pairs on pronoun use also selects fewer refusals, fewer code blocks and fewer tokens (\S\ref{sec:dial}), and the control reported there matches refusals and length but not code blocks. We tried to add code blocks. The pool is not what stops it: of the $269{,}665$ usable preference pairs, $158{,}802$ carry no difference in second-person rate at all, so pairs without a pronoun signal are abundant. The matching is what stops it. Required to reproduce the pronoun-selected set's joint distribution over refusal rate, length and code blocks while carrying no pronoun difference, the largest set we could assemble holds $3{,}348$ pairs, $3{,}346$ in the trained direction; across 3 ways of coding the code-block axis the ceiling runs from $1{,}674$ to $3{,}348$, against the $7{,}537$ pairs each training run uses.}

\vekalet{After submission we ran it at that size and then a person-selected run of the same size: $3{,}346$ of the $7{,}537$ pairs, drawn to the control's strata, same configuration (205 and 206 steps), one training seed each, each registered before training. Changes are per 1,000 tokens, second person first. At $n=3{,}346$ and the same configuration, both runs separate from the reference: person-selected $-3.21$ $[-4.11,-2.53]$; code-matched control with no net person signal $-0.63$ $[-0.95,-0.29]$. Same-size difference $-2.58$ $[-3.52,-1.84]$. The reference is the unselected run at $7{,}537$ pairs, a larger dataset, so the same-size difference is the reading that does not depend on it. Against the SFT base the two are $-2.98$ $[-4.16,-1.92]$ and $-0.40$ $[-1.26,+0.41]$. The person-selected run clears its paired placebo band ($1.00$) and the control does not ($1.31$). The first person does not separate: $-1.58$ $[-1.97,-1.20]$ and $-1.34$ $[-1.75,-0.87]$, difference $-0.24$ $[-0.76,+0.24]$; against the SFT base both intervals include zero ($-0.98$ $[-1.96,+0.14]$ and $-0.74$ $[-1.91,+0.49]$).}

\vekalet{Four limits govern this reading. First, the control matches the share of pairs whose chosen side loses a code block ($6.1\%$ in both), not code volume, the reading that bears on a density (below): the chosen side of the person-selected set carries $+3.5$ code tokens per response and the control's $-5.9$, opposite signs, a contrast we measured on the pairs after the run and did not register. So the same-size difference cannot exclude code volume. Second, the strata match and the means do not: chosen minus rejected, refusals $-0.060$ in the control against $-0.037$, code blocks $-0.033$ against $-0.014$, tokens $-44.4$ against $-22.7$, log length $+0.018$ against $-0.146$. Third, each run is one training seed. The intervals cover prompts and generation seeds, not training seeds; at $7{,}537$ pairs three seeds span $-7.01$ to $-6.89$, and at this size the spread is unmeasured. On the generation-seed scale the full-size runs' registered bar is $1.1$ and the floor for a difference between two runs $1.29$: the control's move is below both and the same-size difference above both. Fourth, this is a smaller dataset than the runs of \S\ref{sec:dial} and does not test them. The debate prompts elicit no code blocks, so output code cannot be read; against SFT, refusals move $+0.001$ and $+0.000$, length $-19.1$ and $-0.5$ characters. At this size the fall in ``you'' is not carried by refusals or by the presence of code blocks; whether code volume or length carries it, this design cannot say. The fall in ``I'' does not separate from the bundle. The code-block confound stays open.}
