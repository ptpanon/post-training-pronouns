\paragraph*{Ordinary instructions, and the band they give.}
\vekalet{The continuation prompt is not an instruction, so we also read the battery on plain instructions. The stimulus is $300$ instructions from Alpaca \citep{taori2023alpaca}, $75$ in each of four classes (summarize, classify, how-to, explain), taken in hash order after dropping every instruction that carries a first- or second-person form of its own, names an addressee genre, contains a code block or runs past $150$ words; the selection rule and the list are in the released repository. The aligned outputs answer through the model's own chat template with no system line; the base checkpoint receives the same instruction inside the URIAL frame \citep{lin2024urial}. Each checkpoint is read at four sampling seeds $\times$ $300$ instructions ($1{,}200$ rows), cells are paired on instruction and seed, a cell enters only if both checkpoints clear the degeneracy shelf, and the base text is cut at its first code fence or new query line (median $36\%$ of base rows). Intervals are instruction-clustered ($1000$ draws) and each model carries its own within-instruction paired placebo. \textbf{Second-person density falls in $16$ of $16$ models with intervals excluding zero, all $16$ above their placebo}, from a base range of $9.09$--$15.71$ per thousand ($1.73\times$) to an aligned $2.70$--$6.24$ ($2.31\times$). \textbf{The band does not open the way the raw-continuation panel's does}: with the task fixed and each pipeline given its own template, the aligned spread stays inside a factor of three. \textbf{The first person falls here too, but not everywhere}: counted directly, first-person forms fall in $12$ of $16$ models with intervals excluding zero, rise in $2$ (Gemma-3-12B and Gemma-3-27B) and are null in $2$ (Qwen2.5-1.5B and Qwen2.5-3B); $14$ of $16$ clear their own paired placebo. (An earlier reading printed a derived measure, first-person forms minus sentence-opening vocatives, which rises almost everywhere; we report the direct count instead.) The mode shares move with the template: continuations are $90\%$ of base rows and $89\%$ of aligned rows (median over models), and the assistant opening drops from $8\%$ to the shelf. Read within mode, the aligned band is $1.85\times$ among continuations ($1.82\times$ at base, $16$ models) and $2.13\times$ among assistant openings ($1.50\times$, $9$ models with at least $80$ rows); refusals and meta rows are too few for a band. \textbf{Instruction class matters more than model}: the aligned band within a class is $1.54\times$ for how-to ($5.23$--$8.07$ per thousand) and $3.92\times$ for explain ($1.62$--$6.36$), but $15.04\times$ for classify ($0.42$--$6.37$) and $19.31\times$ for summarize ($0.31$--$5.93$): on those two classes several models answer with almost no second person at all, so the ratio is a ratio of small numbers and is not read as a spread. This reading is descriptive: the instrument was committed before the run, and no acceptance bound was written (Appendix~\ref{app:sapma}).}
