\paragraph*{A second training seed for the run without a pronoun contrast.}
\vekalet{Registered before training, the same pairs, step count and configuration were trained again with a second seed and read with the first seed's reader. The rate falls by $-1.68$ $[-2.54,-0.88]$, against $-1.20$ $[-2.03,-0.39]$ in the first seed, and clears its paired placebo (95th percentile $1.01$); the generations stay above the degeneracy shelf (distinct-4 $0.77$). Against the gap-removed run's first seed the difference is now $-0.56$ $[-0.82,-0.34]$: in this seed the run without a contrast lowers the rate more than the gap-removed run rather than as much. Both seeds lower it, so the registered outcome holds; how far it falls relative to the gap-removed run depends on the seed.}
